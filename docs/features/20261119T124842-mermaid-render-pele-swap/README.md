# Mermaid renderer swap to Pele

This change replaces the app's Mermaid.js diagram renderer with Pele inside the existing sandboxed runtime page, which runs as an iframe on web and a WebView on native. Work item W381, branch `feat/mermaid-render-pele-swap`, targeting `dev` on the fork. Status: in progress. Start with the [plan](design/plans/mermaid-pele-renderer-swap-plan.md).
